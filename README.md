# 🎬 محرر فيديو - Video Editor Pro

محرر فيديو احترافي للأندرويد بواجهة عصرية ودعم 3 لغات.

## ✨ الميزات

### 🎨 أدوات التحرير
- ✂️ قص وتقسيم الفيديو
- 🔄 تدوير وعكس الفيديو
- 📦 ضغط الفيديو
- ⏩ تغيير السرعة (بسيط ومتدرج)
- 🎬 فيديو داخل فيديو (PiP)
- 🖼️ فيديو فوق صورة

### 📝 النصوص والملصقات
- ✍️ إضافة نص عادي
- 🎨 نص بظل
- 😀 ملصقات وإيموجي
- 🖼️ علامة مائية
- 🖼️ إطارات

### 🎵 الصوت
- 🎼 إضافة موسيقى
- 🎤 تعزيز الصوت
- 🎙️ خفض الموسيقى تلقائياً
- 🔇 حذف الصمت
- 🎚️ تلاشي الصوت
- 🔄 تبديل الصوت

### 🎨 التأثيرات
- ✨ فلاتر بصرية
- 🎬 تأثيرات سينمائية
- 🌈 ضبط الألوان
- 🎨 تلوين الفيديو

### 🎯 إضافات
- 📸 لقطات من الفيديو
- 🎞️ تحويل إلى GIF
- 📱 أبعاد السوشيال ميديا
- 🖼️ صور إلى فيديو
- 🎨 كولاج
- 📊 معلومات الفيديو

## 🌐 اللغات المدعومة

- 🇸🇦 العربية
- 🇺🇸 English
- 🇫🇷 Français

## 📱 متطلبات التشغيل

- Android 7.0 (API 24) أو أعلى
- مساحة تخزين: ~100 MB
- ذاكرة عشوائية: 2 GB أو أكثر

## 🔧 البناء من المصدر

```bash
# 1. استنساخ المستودع
git clone https://github.com/anwarghazali5-creator/video-editor-android.git
cd video-editor-android

# 2. ضع مكتبة FFmpeg في app/libs/
# ffmpeg-kit-full-gpl.aar

# 3. البناء
./gradlew assembleDebug
